# 테스트 결제는 되는데, 라이브에선 안 될 때 (체크리스트)

- **유형**: 체크리스트형 (점검 순서대로), 2장에 "테스트와 라이브는 다른 환경" 문제 정의
- **형식**: 카드뉴스 8장 (1080x1350)
- **축**: 결제연동 / 2026-11-23(월). 셀링 포인트: 둘 다 (D+1 빠른 심사, 개인도 온라인 결제 받기)
- **타깃 페르소나**: 바이브코딩·노코드로 서비스를 만들고 테스트 결제까지 성공한 1인 메이커(개인·비사업자 포함). 배포 후 실제 카드로 결제하자 오류가 나거나 결제수단이 안 보여 "코드는 똑같은데 왜?"에서 멈춘 사람

- **분량 비율**: 정보 6장(1~6) : 홍보 2장(7~8) = 75 : 25 (기준 70:30 이내). 8장은 저장 유도가 먼저, 신청은 한 줄
