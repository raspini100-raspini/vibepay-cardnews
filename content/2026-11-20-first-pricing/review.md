## 확인 결과 (수정 불필요)
- 수수료 계산: 10,000원 x 4.4% = 440원, 10,000원 x 3.3% = 330원으로 정확함. VAT 포함 금액은 표기하지 않음.
- 수수료 맥락: 화면 "예) 4.4%면 1만 원당 440원"은 가정형 계산 예시이고 업계 평균·일반 수수료라는 표현이 없음. 캡션에서 "바이브페이 신용·체크카드 수수료 기준", 개인·비사업자 4.4% / 사업자 3.3%(일반 등급)로 출처와 구분을 밝힘. 화면 본문이 38/40자라 "개인·비사업자 기준"을 더 넣을 수 없어 캡션 표기로 충분하다고 판단함.
- VAT 별도: 화면 장면 2와 캡션에 모두 있음. "실제 조건은 계약 시 안내"는 캡션에 있음.
- 외부 통계·평균 가격·전환율·마진 공식: 없음.
- 세무: 단정하는 문장 없음. 캡션에 세금·부가세는 세무 전문가 확인 단서, 사업자등록·신고 의무는 별도 확인 단서가 있음.
- 장면 6 stat: "D+1 빠른 심사"(영업일 기준·보완 시 연장), "개인도 온라인 결제 받기"(심사·계약 후 이용)가 있고 캡션에도 같은 내용이 있음. 캡션 첫 줄에 강점 2 있음.
- 금지 표현(즉시/당일 승인, 100%, 누구나, 무조건, 심사 없이): 없음. 가격 정하기와 심사 통과를 인과로 연결하지 않음.
- 이벤트·혜택·오픈 기념 문구: 없음(11/20 발행). CTA는 "프로필 링크".
- 글자수(\n, * 제외): 장면 제목 최대 18자(훅), 본문 최대 38자(장면 2), list 항목 12/14/16자로 모두 기준 이내.
- 홍보 비율: 장면 6~7 합 8초 / 전체 28.5초 = 약 28% (30% 이하).
- 월자동결제 FAQ 인용은 brand 51줄 원문과 일치함(어미만 "~방식"으로 끝맺음).
