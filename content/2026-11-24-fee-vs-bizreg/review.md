## 확인 결과 요약
- 수치: 개인·비사업자 4.4%, 사업자 3.3%(일반 등급), 가입비 55,000원(개인·비사업자만, 사업자 면제), 관리비 양쪽 동일, VAT 별도. brand와 일치.
- 계산: 1,000,000원 x 4.4% = 44,000원, x 3.3% = 33,000원, 차이 11,000원. 2,000,000원이면 차이 22,000원. 정확함.
- 세무: 등록 기한(20일), 세율, 간이과세, 금액 기준선 없음. "등록 안 해도 된다", "개인은 손해", 절세 암시 없음. 캡션에 "사업자등록·신고 의무는 판매 상황에 따라 다르니 별도로 확인" + 국세청·세무서·세무 전문가 확인 권유 + 확인일 있음.
- 강점: stat 장면에 D+1 빠른 심사(접수 후 D+1일, 영업일 기준, 보완 시 연장) / 개인도 온라인 결제 받기(심사·계약 후 이용). 캡션 첫 줄에도 강점 및 단서 있음.
- 이벤트 문구, "1~3일", 즉시/당일 승인, 누구나/무조건/100%, 타사명 없음. 훅 과장 없음.

## 수정 내역 (원문 → 수정 | 이유)
1. 장면 2(point 1) body: "4.4%→44,000원 / 3.3%→33,000원 / VAT 별도·계약 시 최종 안내" → "개인 4.4%→44,000원 / 사업자 3.3%→33,000원 / VAT 별도" | 화면만 봐서는 어느 요율이 개인·사업자인지 드러나지 않음. 40자 권장 맞추느라 "계약 시 최종 안내"는 화면에서 뺌(캡션에 남아 있음, "일반 등급"도 캡션에 있음). 39자.
2. 장면 4(point 3) body: "판매가 이어지면 그때 등록 검토 / 신청은 세무서·홈택스에서" → "심사·계약 후 이용해요 / 등록 의무는 세무서·홈택스에서 확인" | "판매가 이어지면 그때 등록"은 처음엔 등록하지 않아도 된다는 뜻으로 읽힐 수 있음(등록 시점은 공식 미확인 사항). "개인으로 먼저 시작" 제목 바로 아래에 이용 조건 단서도 넣음.

## 사람 확인 필요 (법무/세무/사업팀에 물어볼 것)
- 세무: 출처로 쓴 국세청 상담 페이지(call.nts.go.kr)는 검색 스니펫으로만 확인했고 원문은 열지 못함. "계속·반복 판매 여부를 돌아본다"는 흐름이 국세청 취지와 맞는지 확인 권장. 게시를 막을 사안은 아님(구체 기준·기한·세율은 쓰지 않았음).
- 사업팀: 개인으로 계약한 뒤 사업자로 바꿀 때 바이브페이 절차와 3.3% 적용 시점은 brand에 없어서 콘텐츠에 쓰지 않음. 댓글 문의 대비용 답변이 필요함.
