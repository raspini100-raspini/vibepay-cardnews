# 무료 체험 → 유료 전환 설계 기초

> 조사일 2026-11-27. 한계: www.korea.kr, www.law.go.kr, www.ftc.go.kr 직접 열람이 이 세션에서 차단되어(도메인 미허용) 공식 원문을 열지 못했다. 아래 "공식" 표시는 검색결과에 공식 URL이 노출되고 요약이 확인된 것(스니펫)이며, 게시 전 원문 대조가 필요하다. 법률 자문 아님. 커뮤니티 원문(Voice)은 수집 못함(검색 결과는 법률·언론 해설 위주).

## 핵심 요약 (3줄)
1. 무료 체험이 유료 정기결제로 바뀔 때는 전환 전 30일 이내에 소비자 동의를 받고 동의 취소 조건·방법을 알려야 한다는 규정이 2025-02-14부터 시행 중이다(전자상거래법 제13조제6항, 시행령 제20조의2로 보도됨. 원문 미열람).
2. 가입 때 한 번 받은 체크는 별도 동의로 안 본다는 취지의 예시가 지침에 있다고 보도됨. 단 "체험 14일짜리를 가입 시 동의로 처리 가능한가"는 답변 본문을 못 봐 미확정.
3. 카드뉴스 뼈대는 "기간·범위 정하기 → 카드 등록형/무등록형 고르기 → 종료 전 안내 → 금액·주기·해지 고지와 동의 → 해지 쉬운 동선". 바이브페이는 체험 기능이 아니라 월자동결제의 "안내·동의 후 청구" 원칙과 두 강점으로만 연결.

## 불확실/상충 정보
- 위반 제재 수위("영업정지 1년 이내, 과태료 최대 500만 원")는 언론 요약뿐 → 카드 사용 금지.
- 소비자원 피해유형 비율(고지 미흡 34.0%, 해지 제한·방해 32.1% 등)은 검색 요약 수준이고 1차 확인 못함 → 수치 사용 금지.
- 체험 기간이 30일 이내일 때 최초 계약 시 동의를 함께 받아도 되는지: 공정위 답변 본문 미확인(참고 https://www.nepla.ai/wiki/기업과-소비자/공정거래/전자상거래법-상-다크패턴-유형-중-숨은갱신-이란/무료체험-프로모션-기간이-30일-이내라면-최초-계약-시에-유료-전환에-대한-동의를-함께-받아도-되나요-g6w93g3zxnoj , 비공식). 단정 금지, "공정위 문답서 확인" 안내로 처리.
- 무등록형(카드 없이 체험)은 종료 후 유료 결제 시 새로 결제수단을 받으므로 '자동 전환' 이슈가 작다는 설명은 일반 원칙이며 공식 근거 못 찾음. 또한 규정이 개인·소규모 사업자에게 어떻게 적용되는지, 업종별 예외는 미확인.
- 체험 기간 며칠이 적정한지, 카드 등록형이 전환율이 높은지: 1차 출처 없음 → 수치·우열 주장 금지.
- 이용 시점 해지의 효력(즉시/다음 결제일), 잔여기간 환급은 11/18 리서치와 동일하게 확정 근거 없음.

## 카드용 핵심 5~6개 (제안)
1. 체험은 "무엇을, 며칠" 먼저: 체험 범위(핵심 기능 vs 제한)와 기간을 한 문장으로 정하고 가입 화면에 적기. 일반 원칙.
2. 카드 등록형 vs 무등록형: 등록형은 종료 후 자동 전환이 있어 고지·동의 부담이 크고, 무등록형은 종료 후 결제 시점에 새로 안내·동의. 어느 쪽이 낫다는 단정 금지, 장단은 일반 원칙으로 병기.
3. 종료 전 사전 안내: 종료 전에 메일·앱 알림으로 "언제, 얼마, 어떻게 해지" 알리기. 법적으로는 전환 전 30일 이내 동의·고지(공식 스니펫, 원문 확인 전제).
4. 전환 안내에 넣을 3가지: 금액·주기·해지 방법(+동의 취소 방법). 체크박스 사전 체크·창 닫기는 동의로 보지 않는다는 취지(지침 스니펫).
5. 해지는 가입만큼 쉽게: 설정 페이지 1~2번 클릭, 로그인만으로 해지, 해지 기록(메일) 남기기.
6. 연결: 월자동결제는 "금액·주기·해지 조건을 안내하고 동의를 받은 뒤" 청구하는 방식(랜딩 FAQ 원문). 개인·비사업자도 PG 연동으로 온라인 결제를 받을 수 있고(심사·계약 후 이용), 심사는 접수 후 D+1일(영업일 기준, 보완 시 연장 가능).
