# 서비스는 만들었는데, 결제는 어떻게 하죠? — 바이브코더가 결제에서 막히는 3단계
조사일: 2026-11-08 / 범위: 30분 급행. 검색 스니펫 기반이며, 환경 제약으로 docs.tosspayments.com, www.tosspayments.com, techchat.tosspayments.com 원문 페이지는 열람하지 못했음(도메인 접속 불가). 아래 "확인된 사실"은 모두 게시 전 원문 재확인 필요.

## 핵심 요약 (3줄)
1. 3단계 가설(가입·심사 / 연동 / 운영)은 방향이 맞다. 다만 "운영 단계(정산·환불·정기결제)"에 해당하는 국내 1인 개발자 목소리는 이번 조사에서 확보하지 못했다. 카드뉴스에서 운영 단계는 근거가 약하므로 "알아둘 것" 정도로 가볍게 다루길 권한다.
2. 심사 반려의 근거로 확인된 것은 사업자정보 불일치, 환불·약관 등 정책 문서 미비, 통신판매업 신고, 고위험 업종이다. 개인(비사업자) 가입 가능 여부는 공식 근거를 확보하지 못했다.
3. 연동 보안은 "서버에서 주문 금액과 대조한 뒤 승인 API 호출", "웹훅 빠른 200 응답·재시도 대비"가 토스페이먼츠 공식 블로그에서 확인된다. 실제 커뮤니티 불만(Voice)은 거의 못 찾았다.

## 확인된 사실
(확인일 2026-11-08, 전부 검색 스니펫 기반. 게시 전 공식 원문 확인 필수)
- 토스페이먼츠 결제 승인 API를 쓰는 경우, 가맹점 서버는 성공 리다이렉트 URL로 받은 정보를 서버에 저장한 주문 정보와 검증한 뒤 승인 API를 호출한다(공식 블로그). 출처: https://www.tosspayments.com/blog/articles/54253
- 토스페이먼츠 웹훅은 10초 이내 200 응답이 필요하고, 실패 시 최대 7회까지 재전송한다. 엔드포인트를 개발자센터에 등록해야 한다(공식 블로그, 가상계좌 입금 알림 글 기준). 출처: https://www.tosspayments.com/blog/articles/paytech-6
- 토스페이먼츠의 "사업자등록 바로신청"은 통신판매업을 준비하는 개인사업자 대상이며, 사업자등록 면제가 아니라 등록 절차 간소화 서비스다. 출처: https://www.tosspayments.com/blog/articles/business-registration
- 토스페이먼츠가 MCP 서버로 AI 챗봇 연동을 지원한다는 내용과, 기존 연동에 평균 1~2주가 걸렸다는 설명이 있다(검색 요약, 출처 URL 미특정). 게시 전 확인 필요.
- 바이브페이(brand/vibepay.md 기준): 사업자등록 없는 개인도 '개인' 유형으로 신청 가능, 단 업종·운영 방식 확인 후 이용 여부 안내, 자동 승인 아님. 심사는 접수 후 D+1일(영업일, 보완 시 연장 가능). 출처: /home/user/brand/vibepay.md

## 불확실/상충 정보
- 국내 PG가 사업자등록 없는 개인과 직접 계약하는지: 공식 근거 못 찾음(요청한 "개인 장벽 공식 근거 1~2개" 미충족). 확인 후보: 토스페이먼츠·포트원·KG이니시스 가입 안내, 국세청 홈택스 사업자등록 안내, 정부24 통신판매업 신고, 전자상거래법(국가법령정보센터). 접속 가능한 환경에서 재조사 필요.
- 공식 개발자 문서(docs.tosspayments.com)의 금액 검증 문구: 접속 불가로 직접 인용 못 함. 현재 근거는 공식 블로그 글.
- 웹훅 10초·7회 재시도는 가상계좌 글 기준이며 다른 결제수단에도 동일한지 불명.
- 심사 기간 "최대 14일"(카페24 안내 요약)과 바이브페이 "D+1일"은 서로 다른 PG 이야기이므로 비교 표현 금지.
- 5만 원 이상 에스크로 의무, 거절 비율 수치 등은 2차 출처라 사용 보류.
- AI 결제 코드 "90% 맞고 10건당 1건 치명적 오류" 수치는 비공식 추정이므로 사용 금지.

## 후속 조치 제안
1. 게시 전 공식 원문 3종 재확인(토스페이먼츠 개발자 문서의 금액 검증, 웹훅 문서, 사업자 없는 개인 가입 안내).
2. 국세청·정부24·전자상거래법 URL을 확보해 "사실" 항목에 추가.
3. 카드뉴스 1호는 근거가 상대적으로 단단한 2단계(서버 검증)와 1단계(사이트 요건) 중심으로 구성하고, 3단계는 요약만 권장.
