## 핵심 요약 (3줄)
1. 보완 요청 원인은 대부분 "기본 항목 미준비"로 설명된다(공식 블로그 취지): 사이트에 환불·배송·상품 정보가 없거나, 가격이 실제 결제 금액과 다르거나, 신청 정보와 사이트 표기가 어긋나는 경우.
2. 사이트 신원 표시(상호·대표자·주소·연락처 등)는 전자상거래법상 사이버몰 운영자 표시의무와 맞닿아 있고 공정위가 미표시 사업자를 제재한 사례가 있다. 단 비사업자 독자에게 "사업자등록번호 표기"를 일괄 요구하는 식으로 쓰면 안 된다.
3. 업종 확인·서류 식별정보 표기는 PG·카드사별로 다르다. 카드에는 "자주 확인하는 부분" 수준으로만 쓰고 "반드시/통과/반려" 단정 금지.

## 불확실/상충 정보 (카드에 쓰지 말 것)
- "가장 흔한 사유 N가지", 비율, 순위: 근거 없음. "자주 확인하는 부분" 정도로만.
- 사업자정보 표기 상세 항목: PG 체크리스트의 푸터 항목은 이미지 안내라 텍스트 확인 못함. 전자상거래법 항목(상호·대표자·주소·연락처·사업자등록번호)은 사업자 대상이며, 비사업자 개인에게 동일 적용되는지/대체 표기 방식은 미확인 → "판매자 정보(상호 또는 이름·연락 가능한 문의 채널)" 수준 추상 표현만. 사업자등록번호·통신판매업 신고번호를 필수로 단정 금지.
- 전자상거래법 시행규칙 항목은 과거 결정문 인용이라 현행 조문과 다를 수 있음.
- 개인정보처리방침 게시 의무 범위(소규모·개인 포함 여부 등)는 원문 미확인. "법적 의무"로 단정 금지, 개인정보 수집 시 필요하다는 일반 설명도 원문 확인 후.
- 이용약관·개인정보처리방침이 모든 PG 심사의 필수 서류인지: 업종 가이드(사주·운세) 한정 근거뿐 → 일반화 금지.
- 신분증 마스킹 범위, 통장사본 유효기간·형식: PG 일반 기준 미확인. 바이브페이 원문만 사용.
- 서류 정보 불일치 오류 사례(인증서 주민번호 상이 등)는 특정 PG 오류 코드 안내이므로 카드 사용 금지.
- 심사 기간(타 PG 10~14영업일, 7~14영업일 등)은 바이브페이 D+1과 비교 금지.
- "신청 URL이 접속 불가라서 반려" 직접 근거: 검색에서 확인 못함. 간접 근거(폐쇄몰은 테스트 계정 전달, 홈페이지 주소 입력)만 있음 → "심사자가 열어볼 수 있어야" 정도의 일반론으로 표현하고 사유로 단정하지 않는다.

## 카드용 핵심 5~6개 (원인 → 한 줄 처방)
1. 환불·배송(제공 방식) 안내가 사이트에 없어요 → 결제 전 고객이 찾을 수 있는 곳에 적기 (P1, 환불 6칸 구조는 11/18 리서치 참조)
2. 상품·가격이 불분명하거나 결제 금액과 달라요 → 사이트 표시 가격 = 신청서 상품 설명 = 실제 결제 금액 (P2, P3)
3. 판매자 정보·약관·개인정보처리방침이 안 보여요 → 하단(푸터)에 판매자 정보와 약관·처리방침 링크, 법적 필수 범위는 업종·상황별 확인 (P4, P6, 전자상거래법 제10조 취지)
4. 신청서와 사이트·서류 정보가 서로 달라요 → 운영 URL, 이름·상호, 상품 설명, 서류 정보를 한 번 대조 (P4)
5. 로그인해야만 보이고 접속이 안 돼요 → 심사자가 열어볼 수 있는 공개 화면 또는 테스트 계정 안내 (P5, 일반론)
6. 업종·운영 방식 확인이 필요해요 / 서류 식별정보 → 제한·추가서류 가능 업종이 있어 신청 전 확인, 서류는 안내대로 가림·표기 (P7, P8; 바이브페이 서류 안내 원문 인용 가능)
