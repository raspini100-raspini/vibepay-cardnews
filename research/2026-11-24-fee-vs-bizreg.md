## 핵심 요약 (3줄)
1. 바이브페이 수수료는 개인·비사업자 4.4%, 사업자 3.3%(일반 등급), VAT 별도. 차이 1.1%p는 월 결제 100만원 기준 11,000원(VAT 별도).
2. 사업자등록 여부는 수수료 때문만이 아니라, 세법상 계속·반복적으로 판매하는지(사업 실질)로 판단된다. 수수료는 참고 요소일 뿐 등록 의무의 기준이 아니다.
3. 개인 유형으로 시작해 매출이 쌓이면 사업자 전환을 검토하라는 흐름은 가능하나, 전환 시점·세금 영향은 국세청/세무서 확인이 필요하다고 단서를 붙인다.

## 불확실/상충 정보 (릴스에 쓰지 말 것)
- 간이과세 기준 금액: 자료마다 8,000만원/1억 400만원으로 상충 -> 금액 기준선 사용 금지.
- 통신판매업 신고 면제 기준(직전년도 50회 미만 등)은 스니펫 기반, 현행 고시 미확인 -> 수치 사용 금지.
- 부가세·소득세율, "월 몇 원부터 사업자" 같은 기준선: 공식 확인 못 함 -> 사용 금지. "정해진 금액 기준선은 없고 사업 실질로 판단"이라고도 단정하지 말고 "세무서 확인"으로 처리.
- 개인에서 사업자로 전환 시 바이브페이 절차·소요, 기존 계약 변경 방법: brand에 없음 -> 언급 금지(사람 확인 TODO).
- 3.3%는 '일반 등급' 기준. 우대 등급 적용 시 변동 가능하나 구체 수치 brand에 없음 -> 언급 금지.
- 사업자 3.3% 적용에는 사업자 유형 가입이 필요하다는 점은 요금표상 명확하나, 개인 계약 중 전환 시 요율 적용 시점은 불명.
- 사업자등록 시 신고 부담은 사실이지만 구체 내용은 공식 미확인 -> "세금 신고 의무가 생길 수 있어요" 정도도 세무서 확인 단서와 함께.

## 릴스 핵심 포인트 (4~5개)
1. 훅: "수수료 4.4%와 3.3%, 얼마나 차이 날까?" -> 개인·비사업자 4.4% vs 사업자 3.3%(일반 등급, VAT 별도).
2. 계산: 월 100만원 결제 시 44,000원 vs 33,000원, 차이 11,000원(VAT 별도). 가입비 55,000원은 개인만(사업자 면제).
3. 판단 기준: 수수료만이 아니라 "계속·반복해서 판매하는가"가 사업자등록 고민의 출발점(국세청 취지). 금액 기준선 언급 금지.
4. 절차 개요: 사업자등록은 사업 개시일부터 20일 이내 세무서 신청(홈택스 가능) - 공식 재확인 후 사용, 미확인 시 "세무서·홈택스에서 신청"까지만.
5. 바이브페이 장면(강점 2가지 가장 크게): "개인도 온라인 결제 받기(심사·계약 후 이용)" + "D+1 빠른 심사(영업일 기준, 보완 시 연장 가능)". 개인으로 먼저 시작 -> 이후 필요 시 사업자 검토.
