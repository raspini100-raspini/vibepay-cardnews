# 인스타그램 자동 게시 설정 (상세)

> Meta 화면의 메뉴 이름은 수시로 바뀝니다. 이름이 조금 달라도 같은 위치의 비슷한 메뉴를 고르면 됩니다. 막히면 화면 캡처를 보내주세요.

## 0. 먼저: Facebook 페이지는 필요 없습니다 (경로 변경)
Meta는 2024년부터 **"Instagram 로그인을 사용하는 Instagram API"**를 제공합니다. 이 방식은 Facebook 페이지 연결 없이 인스타그램 비즈니스/크리에이터 계정만으로 게시·인사이트 조회가 됩니다. 이 방식으로 진행합니다 (게시 스크립트도 이 방식에 맞췄습니다).
- 이미 프로페셔널(비즈니스) 계정 전환을 마치셨다면 → 1단계부터
- 아직이면: 인스타그램 앱 → 프로필 → 오른쪽 위 ☰ → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → 비즈니스

## 1. Meta 개발자 계정 만들기 (5분)
1. PC 브라우저에서 https://developers.facebook.com 접속 → 오른쪽 위 **로그인** (Facebook 계정 필요. 개인 계정이어도 됩니다)
2. 처음이면 **시작하기** → 휴대폰/이메일 인증 → 직업 선택(개발자 등)까지 마치면 개발자 계정이 됩니다.

## 2. 앱 만들기 (5분)
1. 오른쪽 위 **내 앱** → **앱 만들기**
2. 앱 이름: `VibePay Cardnews` / 앱 연락처 이메일: 회사 메일
3. **사용 사례** 화면에서 **"Instagram에서 메시지 및 콘텐츠 관리"** (영문: *Manage messaging & content on Instagram*) 선택 → 다음
4. 비즈니스 포트폴리오 연결을 물으면 **지금은 연결 안 함** 선택해도 됩니다 → **앱 만들기**

## 3. 인스타그램 계정 연결 + 토큰 발급 (10분)
1. 앱 대시보드 왼쪽 메뉴 **사용 사례** → Instagram 항목의 **사용자 지정(Customize)**
2. **"Instagram 로그인을 통한 API 설정"** (*API setup with Instagram login*) 화면으로 이동
3. **① 필수 메시지 권한 추가** 같은 단계는 건너뛰고, 권한 목록에서 아래 3개가 추가돼 있는지 확인 (없으면 **추가**):
   - `instagram_business_basic`
   - `instagram_business_content_publish` ← 게시
   - `instagram_business_manage_insights` ← 조회수 등 인사이트
4. **② 액세스 토큰 생성** 섹션 → **계정 추가** → 인스타그램 로그인 창에서 **@vibepay2026**으로 로그인 → 권한 허용
5. 목록에 @vibepay2026이 나타나면:
   - 계정 옆 숫자 **ID** (17~18자리) → **이 숫자를 채팅으로 알려주세요** (비밀 아님)
   - **토큰 생성** 버튼 → 긴 문자열(토큰)이 나옵니다. 이 화면을 **열어둔 채로** 저에게 "토큰 준비됐어요"라고 말해주세요.
6. ⚠️ 토큰은 **채팅·이메일·카톡에 절대 붙여넣지 마세요.** 제가 보안 입력 창을 띄우면 그 창에만 넣습니다. 저는 값을 볼 수 없고, 이 클라우드 환경이 Meta로 요청을 보낼 때만 자동으로 붙습니다.
7. 앱은 **개발 모드** 그대로 둡니다. 대표님 본인 계정에만 게시하므로 앱 심사(App Review)나 라이브 전환이 필요 없습니다.

### 토큰 만료 관리
- 이 화면에서 만든 토큰은 **약 60일** 유효합니다.
- 만료 전에 같은 화면에서 **토큰 생성**을 다시 누르고 보안 입력 창에 새로 넣으면 됩니다. (원하시면 만료 1주 전에 알려드리는 예약 알림을 걸어드릴게요.)

## 4. 이미지 공개 저장소 (GitHub, 10분)
인스타그램 API는 파일을 직접 받지 않고 **누구나 열 수 있는 이미지 주소**에서 가져갑니다.
1. https://github.com 가입/로그인 (회사 계정 권장)
2. 오른쪽 위 **+** → **New repository**
   - Repository name: `vibepay-cardnews`
   - **Public** 선택 (카드 이미지는 어차피 인스타에 공개되는 내용이라 괜찮습니다. 이 저장소에는 이미지와 캡션만 올리고, 토큰·고객정보는 절대 올리지 않습니다)
   - **Add a README file** 체크 → **Create repository**
3. Claude와 GitHub 연결: https://claude.ai/connect-github 접속 → GitHub 계정 연결 → **Claude GitHub App 설치** 화면에서 `vibepay-cardnews` 저장소 선택(또는 All repositories)
4. 저장소 주소를 채팅으로 알려주세요 (예: `github.com/<아이디>/vibepay-cardnews`)

## 5. 다 되면 제가 하는 일
1. 이 환경에서 `graph.instagram.com` 접속 허용 요청 (승인 창이 뜹니다)
2. 토큰 보안 입력 창 띄우기 → 대표님이 입력
3. 이미지를 GitHub 저장소에 업로드 → 공개 주소 확인
4. 게시 점검(dry run) → 대표님 "승인" → 게시 → 링크를 마케팅 허브에 기록
5. 인사이트(조회수·저장·댓글) 자동 수집을 마케팅 허브에 연결
